---
title: Analyze Transaction
openapi: 'POST /analyze'
description: Evaluates a transaction against all active rules and returns a real-time risk decision.
---

## Overview

The **Transaction Processing Engine** evaluates incoming transactions against all
currently active dynamic risk rules and produces a deterministic decision.

The evaluation is stateless, real-time, and does not require rule engine redeployment.

---

## Data Dictionary
### Schema Parameters


| Parameter           | Type   | Required | Description                                      |
| :------------------- | :------ | :-------- | :------------------------------------------------ |
| rule_name           | String | Yes      | Human-readable name for the rule.                |
| category            | Enum   | Yes      | Classification: MANDATORY, ACQUIRER-SPECIFIC, TPAP-SPECIFIC. |
| trigger_condition   | Object | Yes      | The logical expression (AND/OR or base comparison). |
| action              | Object | Yes      | Defines the result if the rule triggers (e.g., DECLINE). |
